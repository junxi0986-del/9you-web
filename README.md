📖 项目简介
九游项目跟踪管理平台是一款专为项目运营、收益统计、账户回本管理打造的轻量化 Web 管理工具。摒弃复杂的后端部署流程，基于原生 HTML+CSS+JS 开发，搭配 Supabase 云端数据库（数据库 + Realtime 实时推送 + 对象存储）实现数据持久化、账号登录、跨设备同步能力。
平台核心用于记录多项目、多账户的投入本金、回本流水、回本进度，自动统计汇总数据，支持台账明细查询、批量数据操作、数据导入导出；同时提供公共项目广场（管理员发布/置顶/加星）、站内公告、市场参考价、项目群聊等协作能力，完美适配日常项目收益跟踪、回本复盘、团队协作、数据归档场景。
正式站点：https://9you.help/ （Cloudflare Pages 自动部署，推送代码后约 75 秒生效）

✨ 核心特色
- ☁️ 云端数据永久保存：基于 Supabase 云端数据库，数据不绑定本地设备，刷新、换设备、重启浏览器数据不丢失
- 🔑 验证码免密登录：6 位邮箱验证码一键登录，滑动拼图人机验证防刷，邮箱后缀快捷选择，会话自动刷新、无感持久化登录
- 📱 Android 原生 APP：WebView 壳打包 APK，支持文件上传、长按保存图片、沉浸式状态栏、边缘手势排除、APP 内自动更新检测
- 📈 智能数据统计：自动计算本金、累计收益、回本进度百分比；未回本时显示「距回本 XXX 元」、全部回本后显示「利润 XXX 元」，状态一目了然
- 🏛️ 公共项目广场：管理员统一发布公共项目，支持置顶、加星标，用户新建项目时可选公共项目作为数据源
- 💬 项目群聊：基于 Supabase Realtime 的实时群聊，文字/图片消息、2 分钟内撤回、未读闪烁与桌面通知、自定义昵称
- 💰 市场参考价：管理员录入每日市场价（支持按份计价如 2100 个=10 元、小数点后 3 位精度），首页横幅滚动展示，支持双模式回本录入（直接金额 / 按市场价×数量自动计算）
- 📢 站内公告：首页横幅滚动 + 公告页签，最新动态即时触达所有用户
- 📤 项目分享导入：一键生成项目分享码（含账户与回本记录），导入即用，团队协作零门槛
- 💾 数据备份还原：一键导出 JSON 备份、导入备份数据，支持全覆盖数据恢复，杜绝数据丢失
- 🌗 深色模式：亮/暗主题一键切换，跟随系统偏好，偏好本地双保险存储
- 📱 全端自适应：完美适配电脑、手机、平板，移动端液态玻璃底部导航 + 卡片式布局，左右滑动切换页签

🧩 功能清单
1. 账号权限模块
- 邮箱验证码免密登录（6 位验证码，无密码，验证码即登即用）
- 发送验证码前滑动拼图人机验证，防脚本刷码
- 邮箱后缀下拉快捷选择（@qq.com 等，输入框只需填账号名）
- 退出登录二次确认，防误触
- 会话自动刷新、持久化无感登录
- 账号数据隔离，不同用户数据独立不互通
- 管理员体系：公共项目发布、公告管理、市场价录入、群聊管理（前端 ADMIN_EMAILS + Supabase RLS 双重校验）
2. 项目管理模块
- 新增、编辑、删除项目，项目备注自定义填写
- 新建项目可选公共项目作为数据源
- 分享项目：生成分享码（含全部账户与回本记录），一键复制发送
- 导入项目：粘贴分享码，确认摘要后归入自己名下（ID 冲突自动去重）
- 全局项目汇总统计（总人数、总本金、总收益、回本状态）
- 项目卡片可视化展示核心数据，手机端双列卡片布局
3. 账户管理模块
- 单条新增、编辑、删除账户信息
- 批量导入添加账户（支持自定义格式解析）
- 自定义账户 ID（必填）、姓名、本金、上车日期、备注
- 精准搜索筛选账户数据
- 账户列表按创建时间升序排列
4. 回本数据管理
- 单条/批量录入回本金额，支持补录过往时间数据
- 双模式录入：直接输入金额 / 选择市场价品名×数量自动计算
- 直接金额换算确认：自动识别未确认账单，按品名匹配市场价反推出货数量，支持逐笔确认与全部确认
- 自动计算剩余未回本金额、回本进度
- 回本状态智能标记：未回本显示「距回本」、已回本显示「已润 XX」（利润金额）
- 个人台账明细查询、时间排序、单条记录删除
- 数量整数校验：非整数时添加回本金额优先提示，账单确认红标提示
5. 公共项目广场（管理员）
- 管理员发布、编辑、删除公共项目
- 置顶、加星标排序（置顶 > 星标 > 普通）
- 发布者统一显示「九游」，隐藏管理员邮箱
- 用户新建项目时下拉选择公共项目作为数据源
6. 公告模块
- 首页公告横幅滚动展示最新动态（长度随屏幕自适应）
- 公告页签列表，默认展开详情，点击折叠
- 管理员发布、编辑、删除公告
7. 市场价模块
- 管理员录入每日市场参考价（支持同日多条）
- 支持按份计价（如 2100 个宝石=10 元）和小数点后 3 位精度
- 首页横幅滚动展示最新一日价格
- 历史价格查询：桌面端表格 / 移动端卡片式布局
- 点击任意记录复制卖方 ID，系统弹窗提示是否添加出货账单并跳转对应项目
8. 项目群聊模块
- 实时文字（500 字）与图片消息（自动压缩、点击放大）
- 自己的消息 2 分钟内可撤回（桌面悬停 / 移动长按）
- 进入群聊自动加入并广播系统提示，实时显示成员数
- 自定义群聊昵称（与我的页用户名双向同步）
- 新消息标题闪烁提醒 + 桌面通知（可开关）
- 管理员清空群聊记录（二次确认，全员实时同步）
9. 账单与回本明细
- 生成账单独立页面，移动端 5 列布局（编号 | 项目ID | 出货数量 | 今日市场价 | 统计）
- 今日回本明细弹窗与出货账单列表样式统一，含实时跳动时钟
- 账单图片含可见平铺水印（平台名、用户邮箱、账单号）和不可见 LSB 水印
- 支持上传出货截图作为凭证，手机端无横向滚动
- 复制今日出货数量功能，按项目汇总
10. 数据工具模块
- 一键导出全部数据 JSON 备份
- 导入备份文件恢复数据（兼容新旧版本数据格式）
- 一键清空全部数据（带输入验证确认防误操作）
11. 界面体验模块
- 深色模式一键切换，跟随系统偏好，localStorage + Cookie 双保险记忆
- 移动端液态玻璃底部椭圆导航（backdrop-filter 模糊 + 双模式主题）
- 底部导航 4 页签（我的项目 / 公共项目 / 市场价 / 我的），群聊入口在「我的」页
- 手机端首页左右滑动切换导航页签（平移动画 + 实时跟手 + 方向锁定）
- PC 端导航切换动画（与手机端一致的滑入滑出效果）
- 页签内容联动：公告/市场价页自动隐藏对应横幅，页面不重复
- 模态弹窗居中小卡片（非全屏），内部滚动适配长内容

🛠️ 技术栈
- 前端基础：HTML5 + CSS3 + 原生 JavaScript（无框架、轻量无依赖，单文件应用）
- 云端服务：Supabase（PostgreSQL 数据库 + RLS 行级权限 + JS SDK v2）
- 实时能力：Supabase Realtime（群聊消息/成员实时推送、未读提醒）
- 对象存储：Supabase Storage（群聊图片，前端自动压缩上传）
- 人机验证：原生 Canvas 滑动拼图（鼠标/触屏 Pointer Events 适配）
- 样式适配：原生 Flex/Grid 布局、CSS 变量主题、响应式设计、移动端自适应
- PWA：manifest.json + Service Worker（页面网络优先、静态资源缓存优先、版本文件网络优先）
- Android APP：WebView 壳 + edge-to-edge 沉浸式状态栏 + 系统手势排除 + WebChromeClient 文件选择器 + 长按保存图片 + APP 内自动更新检测
- 部署：Cloudflare Pages 自动部署（Git 推送即上线）
- 交互体验：原生动画、Toast 消息提示、二次确认弹窗、回车快捷操作

🚀 使用方式
1. 浏览器访问 https://9you.help/（推荐 Chrome / Edge / Safari 现代浏览器）
2. 输入邮箱账号名（选择后缀）→ 滑动拼图验证 → 收取 6 位验证码登录

iOS 用户：
8. 使用 Safari 打开 → 分享按钮 → 添加到主屏幕 → 全屏无地址栏体验
注意：请通过在线站点访问；本地 file:// 方式打开仅可预览界面，登录、群聊等依赖云端的功能无法正常使用。

⚠️ 部署与使用须知
- 纯前端运行：本项目为纯单页 HTML 应用，无自建后端服务，托管于 Cloudflare Pages，仅需浏览器即可运行。
- 云端数据绑定：所有数据存储在内置 Supabase 云端数据库，独立账号隔离，不同用户数据互不干扰；管理员操作受前端 + RLS 双重校验。
- 网络要求：登录、数据同步、群聊、备份还原需要联网，离线状态仅可查看本地缓存页面，无法保存数据。
- 数据安全建议：建议定期导出 JSON 备份，防止云端异常导致数据丢失；请勿随意分享账号邮箱验证码。
- 浏览器适配：支持 Chrome、Edge、Safari、Firefox 主流现代浏览器，不兼容老旧低版本浏览器；浏览器跟踪防护可能拦截部分本地存储，平台已做 Cookie 降级兼容。

🔐 隐私与数据说明
- 项目仅收集用户登录邮箱、项目数据、账户台账数据、群聊消息与图片、市场价数据，无任何隐私窃取、无后台上传隐私信息。
