📖 项目简介
九游项目跟踪管理平台是一款专为项目运营、收益统计、下级回本管理打造的轻量化 Web 管理工具。摒弃复杂的后端部署流程，基于原生 HTML+CSS+JS 开发，搭配 Supabase 云端数据库实现数据持久化、账号登录、跨设备同步能力。
平台核心用于记录多项目、多下级的投入本金、回本流水、回本进度，自动统计汇总数据，支持台账明细查询、批量数据操作、数据导入导出，完美适配日常项目收益跟踪、回本复盘、数据归档场景。

---
✨ 核心特色
- ☁️ 云端数据永久保存：基于 Supabase 云端数据库，数据不绑定本地设备，刷新、换设备、重启浏览器数据不丢失
- 👤 完整账号系统：支持邮箱注册、密码登录、密码重置、会话自动刷新，无感持久化登录
- 📈 智能数据统计：自动计算本金、累计收益、剩余未回本金额、回本进度百分比，区分已回本/未回本状态
- ⚡ 批量高效操作：支持批量添加下级、批量录入回本金额、批量删除数据，大幅提升办公效率
- 📋 完整台账记录：每笔回本流水独立存档，支持时间升降序排序、单条记录删除，溯源清晰
- 💾 数据备份还原：一键导出 JSON 备份、导入备份数据，支持全覆盖数据恢复，杜绝数据丢失
- 📱 全端自适应：完美适配电脑、手机、平板，移动端自动切换卡片式布局，随时随地查看管理数据
- 🎨 极简高颜值界面：现代化蓝白主题，进度条状态分级展示（正常/慢速/已回本），数据可视化清晰直观
- 🔍 精准搜索筛选：支持按姓名、下级ID、备注模糊搜索，快速定位目标数据

🧩 功能清单
1. 账号权限模块
- 邮箱注册、密码登录、退出登录
- 忘记密码、邮件重置新密码
- 会话自动刷新、持久化无感登录
- 账号数据隔离，不同用户数据独立不互通
2. 项目管理模块
- 新增、编辑、删除项目
- 项目备注自定义填写
- 全局项目汇总统计（总人数、总本金、总收益、平均进度、回本人数）
- 项目卡片可视化展示核心数据
3. 下级管理模块
- 单条新增、编辑、删除下级信息
- 批量导入添加下级（支持自定义格式解析）
- 自定义下级ID、姓名、本金、上车日期、备注
- 精准搜索筛选下级数据
4. 回本数据管理
- 单条/批量录入回本金额，支持补录过往时间数据
- 自动计算剩余未回本金额、回本进度
- 回本状态智能标记（已回本/未回本）
- 个人台账明细查询、时间排序、单条记录删除
5. 数据工具模块
- 一键导出全部数据 JSON 备份
- 导入备份文件恢复数据（兼容新旧版本数据格式）
- 一键清空全部数据（带二次确认防误操作）

- 前端基础：HTML5 + CSS3 + 原生 JavaScript（无框架、轻量无依赖）
- 云端数据库：Supabase JS SDK v2

- 交互体验：原生动画、Toast 消息提示、二次确认弹窗、回车快捷操作

⚠️ 部署与使用须知
- 纯前端运行：本项目为纯单页 HTML 应用，无后端服务、无服务器部署流程，仅需浏览器即可运行。
- 云端数据绑定：所有数据存储在内置 Supabase 云端数据库，独立账号隔离，不同用户数据互不干扰。
- 网络要求：登录、数据同步、备份还原需要联网，离线状态仅可查看本地缓存页面，无法保存数据。
- 数据安全建议：建议定期导出 JSON 备份，防止云端异常、账号退出导致数据丢失；请勿随意分享账号密码。
- 浏览器适配：支持 Chrome、Edge、Safari、Firefox 主流现代浏览器，不兼容老旧低版本浏览器。

🔐 隐私与数据说明
